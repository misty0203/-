甲衛 V5｜115年7月1日修法＋專業情境綜合練習題庫
更新日期：2026-10-17

一、這次修正了什麼？
1. 更換 V4 單調的 TWA／加成指數重複題，改成 140 道不同情境題。
2. 覆蓋 14 個主題：115新法與生效時程、承攬統合與設計風險、監測採樣與SEG、化學品分類與管理、通風控制與缺氧、噪音熱危害與個防、職業健康與人因心理、毒理流病與統計判讀、跨領域計算、術科申論、粉塵及防爆、鉛及特化、照明與輻射、綜合危害。
3. 題型：89單選、17複選、16數值、16申論、2是非。
4. 124題提供教學用程式計分，16題申論提供參考擬答及配分規準，作答後寫入 Supabase 但不假裝自動給分。
5. 題庫從 GitHub 的 questions.csv 自動載入；使用清潔的暫時題庫，原先重複匯入的493題不會污染新版抽題。
6. Supabase 已有的正式作答紀錄保留不刪，繼續寫入你原有的 oh_exam_sessions 及 oh_exam_answers 兩張表；雲端紀錄頁可下載備份 CSV。
7. 提供「法規生效日」頁面，提醒115年已施行及116/117/118年仍在過渡中的條款，不提前套用。
8. 每次診斷盡量涵蓋不同主題；最多30題，避免只抽到同一個計算類型。

二、用手機 GitHub 更新（不用寫程式）
1. 請先登入現有甲衛網站，到「雲端紀錄」下載備份一次。舊V4若已有作答紀錄，備份是額外保護。
2. 解壓縮此 ZIP，在 GitHub 儲存庫 https://github.com/misty0203/- 的 main 分支上傳包內四個檔案：
   app.py（覆蓋）
   core.py（覆蓋）
   cloud_store.py（覆蓋，雲端存取程式維持原有格式）
   questions.csv（覆蓋）
   注意：GitHub 手機若顯示檔名「核心.py」，可能是瀏覽器翻譯，真正檔名必須是 core.py。
3. README_使用說明.txt 與 題目與答案_完整檢視.json 是參考檔，不是網站啟動必需檔，可以不上傳。
4. 將四個檔案上傳至 GitHub 專案根目錄、Commit changes 到 main；等待 Streamlit 自動更新。
5. 重新整理 https://oh-exam-misty0203.streamlit.app/ ，使用原本 APP_PASSWORD 登入，確認顯示140題。
6. 新版沿用原有 Streamlit Secrets（SUPABASE_URL、SUPABASE_SECRET_KEY、APP_PASSWORD），不用重建 Supabase 或重貼密碼。
7. 在「章節練習」作答一題，按「提交並存入雲端」；再去「雲端紀錄」確認作答新增、下載一次備份。

三、法規與試題的重要聲明
- 本題庫全部是 AI 協助製作的「自編模擬題」，不是職業安全衛生管理技術士官方歷屆原題，不是官方標準答案，也沒有經獨立持證職業衛生技師逐題審查。
- 「計算已驗證」意指題目在其明示假設下以程式重新驗算；「自編教學核對」表示提供教學性自動計分，並不表示官方或外部專家審定。
- 已找到 115年第2梯次官方試卷索引，但官方原卷尚未完成逐題比對，故不能保證完全排除115-2已出考點。此版沒有照抄原卷題幹，改以案例情境重新命題。重要法規主題可能重複考，不能為了避重全面捨棄。
- 現行適用基準為115年10月17日。116、117、118年分期施行規定均須按具體條文及施行日核對。
- 法規參考首頁：https://www.osha.gov.tw/48110/48713/207079/207115/207278/post
- 監測法規：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0060033
- 容許暴露標準：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0060004
- 題庫完整 CSV 的 source_url、law_reference、law_version 欄位提供逐題查核線索。並非法律意見，報考請以當次公告與現行法為準。
